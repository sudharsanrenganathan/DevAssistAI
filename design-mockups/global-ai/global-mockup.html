Binary Search in Java

Binary search finds an item in a sorted array by repeatedly halving the search range — much faster than checking every element.
JAVA ❐ Copy
public static int binarySearch(int[] arr, int target) { int lo = 0, hi = arr.length - 1; while (lo <= hi) { int mid = lo + (hi - lo) / 2; // avoid overflow if (arr[mid] == target) return mid; if (arr[mid] < target) lo = mid + 1; else hi = mid - 1; } return -1; // not found }
Each loop cuts the range in half, so the time complexity is O(log n).
