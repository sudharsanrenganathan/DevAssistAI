🚀 Offline Studio

Once set up, use Chat and Docs entirely on your machine — no internet, no account. Add the embedding model for document Q&A on large files:

ollama pull nomic-embed-text

1 Download Ollama

Get the engine required to run models locally.

Go to Ollama.com

2 Pull the Models

Open your terminal/command prompt and run both (chat model + document embedding model):

ollama pull llama3
ollama pull nomic-embed-text

3 Keep Server Running

Start Ollama so the browser can reach it, and keep it running:

OLLAMA_ORIGINS=* ollama serve

Windows PowerShell: $env:OLLAMA_ORIGINS="*"; ollama serve

4 Open the Studio

Launch the offline Chat & Docs workspace.
