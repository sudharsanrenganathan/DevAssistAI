Run DevAssist on your own machine
Offline Studio talks straight to a local AI model on your computer — no internet, no account, nothing leaves your device. Three one-time steps:
1
Install Ollama (the local engine)
A tiny app that runs open AI models on your machine.
Go to Ollama.com ↗
2
Pull the models
In your terminal. The chat model powers Chat & Docs; the embed model makes Docs understand large files.
ollama pull llama3
ollama pull nomic-embed-text
3
Allow this page to reach Ollama
Start Ollama so it accepts requests from the browser, then keep this window open:
OLLAMA_ORIGINS=* ollama serve
On Windows PowerShell: $env:OLLAMA_ORIGINS="*"; ollama serve
