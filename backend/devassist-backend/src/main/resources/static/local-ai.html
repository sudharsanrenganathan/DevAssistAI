Run DevAssist on your own machine
Offline Studio runs a real AI model on your own computer — the AI never touches the internet and nothing leaves your device. Do the one-time setup once; after that it's just open & Connect.
⚙ One-time setup — do this once
1
Install Ollama (the local AI engine)
A small, free app that runs open AI models on your machine. Download it, run the installer, and it starts on its own — you'll see an Ollama icon in your taskbar (Windows) or menu bar (Mac).
Download Ollama ↗
2
Download the two AI models
Open a terminal — on Windows that's Command Prompt (press Win, type cmd, Enter) — and run these one at a time. The chat model powers Chat; the embed model lets Docs read large files. (~5 GB total, downloaded once.)
ollama pull llama3
ollama pull nomic-embed-text
✅ Verify: run ollama list — you should see both llama3 and nomic-embed-text.
3
Let the browser reach Ollama (saved permanently)
By default Ollama blocks web pages. This one command saves a permanent setting so you never touch a terminal for it again. Pick your system:
In Command Prompt or PowerShell (both work — setx saves it forever):
setx OLLAMA_ORIGINS "*"
You'll see “SUCCESS: Specified value was saved.” Then restart Ollama so it picks up the setting: right-click the Ollama icon in the system tray → Quit, then reopen Ollama from the Start menu.
In Terminal — then restart Ollama (menu-bar icon → Quit, reopen):
launchctl setenv OLLAMA_ORIGINS "*"
Simplest — run Ollama in a terminal with the setting and keep the window open:
OLLAMA_ORIGINS=* ollama serve
To make it permanent, add Environment="OLLAMA_ORIGINS=*" to the ollama systemd unit and sudo systemctl restart ollama.
🔒
On Chrome/Edge, if Connect fails with a “loopback address space” error: recent Chrome blocks websites from reaching your computer. Click the tune/site-info icon at the left of the address bar → Site settings → set Local network access to Allow → reload this page. (Firefox doesn't need this step.)
4
Optional — install as an offline app
This page loads from the web the first time. Install it once and it opens later with no internet at all (the AI already runs on your machine). Use the ⬇ Install as offline app button below — then launch DevAssist Offline from your desktop any time.

✓

2. Open this page — or your installed DevAssist Offline app if you did step 4.
